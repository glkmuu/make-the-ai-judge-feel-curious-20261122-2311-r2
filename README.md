A short text about a lighthouse keeper that intrigues the AI judge reading it: a light answered from a place where the charts say there is nothing at all.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This writes the text to `out/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set). Python 3.13, standard library only, no network. The program is deterministic: every run writes the same bytes.
